# Code of conduct

This project is for people who make and enjoy streaming tools. Everyone is welcome here.

## Our standard

- Be kind, patient and respectful. Assume good intentions and ask when something is unclear.
- Give feedback on the work, not the person. Be specific and constructive.
- No harassment, discrimination, personal attacks, trolling, or sharing other people's private information.
- Keep discussions on topic and welcoming to beginners; not everyone has the same experience.

## Scope

This applies to issues, pull requests, discussions and any space where someone represents the project.

## Enforcement

Maintainers may edit or remove comments, close threads, or block people who break these rules. To report a problem,
contact the maintainer through GitHub (a private message or the repository's Security tab for sensitive matters).

This is a short statement in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org).
